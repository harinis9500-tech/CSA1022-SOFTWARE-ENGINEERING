# CSA1022 – Software Engineering Lab

This repository contains sample visual outputs for the 25 experiments listed in the uploaded Software Engineering lab sheet.

## Lab Experiments

Open the `Lab Experiments` folder. Each experiment has a separate folder with an `Output.svg` image.

**Note:** These are generated illustrative lab-output screens based on the experiment requirements. They are not live screenshots captured from Jira, Figma, Docker, Kubernetes, or other external applications. Use them as visual references and replace them with actual application screenshots when your instructor requires proof of execution.
